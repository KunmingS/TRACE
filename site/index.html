Video-based Temporal Recognition and Annotation of Continuous Ethograms of Animal Behavior

V-TRACE

Label a few recordings in the browser, train a detector on them, and have it annotate the rest. The annotator is one static page that reads and writes files on your own machine; training and prediction run from the command line.

Quick Start

Install, then run it with no arguments.

Create a Python 3.9+ environment with conda, mamba, or uv first. vtrace opens an interactive session and starts the annotator with it, so nothing has to be launched by hand — open the address it prints in Chrome or Edge. Type the rest of the commands at the vtrace > prompt without repeating the program's name. Training, evaluation and prediction need a CUDA-capable PyTorch environment; annotation does not. 

# conda
conda create -n vtrace python=3.11 pip
conda activate vtrace

# mamba
mamba create -n vtrace python=3.11 pip
mamba activate vtrace

# uv
uv venv --python 3.11 --seed .venv
source .venv/bin/activate

python -m pip install vtrace-behavior
vtrace prepare --weights all
vtrace

Demo

The whole CalMS21 benchmark, in one command.

The demo is the complete Task-1 mouse social-behavior benchmark in its official split — 70 training videos and 19 test videos. V-TRACE re-hosts none of it: the annotation CSVs ship with the package, and the videos come straight from the official CalMS21 release, one at a time over HTTP range requests, so nothing pulls the 28 GB archive and an interrupted fetch resumes where it stopped. Predicting takes about a minute; training is a real run on the full benchmark. 

vtrace demo predict
vtrace demo download
vtrace demo train

Workflow

From labeled video to predictions.

01

Annotate

Open the annotator, choose a video folder, and mark behaviors on the timeline. Everything is read and written on the computer running the browser — nothing is uploaded and there is no server-side state.

02

Train

Name the video/annotation pairs for the run. V-TRACE indexes each video whole, splits train and validation by recording rather than by window, and writes a timestamped model directory.

03

Evaluate

Score the trained model on the run's own validation split, or pass a fresh set of video/annotation pairs to score it on held-out recordings.

04

Review

Prediction writes one file per video beside it. Open that folder in the annotator to accept, reject, or correct each predicted bout where the labeling happened.

Training Data

Use explicit video and annotation pairs.

The annotation CSV format is time-based: each row maps a behavior label to start and end times in seconds. A single source video can have several CSVs beside it, and each training pair chooses which one to use. 

labelId,timestamp,endTimestamp
grooming,12.430,18.970
rearing,42.100,45.650

Prediction Output

One file per video, replaced on re-run.

A prediction lands as <video>.predict.csv next to the video it describes. Re-running replaces it rather than piling up timestamped folders, so a video has exactly one current prediction — and the file is in the shape the annotator imports, so predictions are reviewed where the labeling happened. 

my_video.mp4
my_video.predict.csv

UI + CLI

The app writes the command for you.

Pick the folder and the recipe in the browser and the configuration screen builds the exact command, ready to paste. A browser is never told where a picked folder lives, so the local server passes along the directories it can see and the page resolves the folder by name. 

vtrace train --model maev2b \
  --video-path /data/my_dataset \
  --pairs video01.mp4=video01.csv

CLI Reference

Core commands.

Each also works from a shell, prefixed with vtrace.

Command Purpose Example
vtrace Open the interactive session and start the annotator. vtrace
vtrace app Serve the annotator on its own, without the session. vtrace app --port 8765
vtrace demo Download and run the CalMS21 walkthrough. vtrace demo predict
vtrace prepare Download model weights ahead of time. vtrace prepare --weights all
vtrace train Prepare the named pairs and train a detector. vtrace train --model maev2b --video-path /data --pairs video01.mp4=video01.csv
vtrace eval Evaluate a trained model, optionally on new paired data. vtrace eval --model-dir /data/model_YYYYMMDD_HHMMSS
vtrace predict Predict on new videos and write a file beside each one. vtrace predict --model-dir /data/model_YYYYMMDD_HHMMSS --input /data/video03.mp4
vtrace pipeline Run prep, train and predict end to end. vtrace pipeline --train --infer --model maev2b --video-path /data --input /data/new
vtrace update Check PyPI for a newer release and offer to install it. vtrace update --check-only

Artifacts

Model runs are self-contained.

Training creates model_YYYYMMDD_HHMMSS/ under --output. Alongside the checkpoint and class map it writes config_resolved.py — the configuration the run actually used, with its bases merged and every override applied. Prediction loads that, so a later edit of the config it started from cannot change how a finished model is rebuilt.

best.pth classmap.txt config_resolved.py dataset.json eval_YYYYMMDD_HHMMSS/

Models

Weights download themselves.

Configurations name their backbone by filename. Any registered name is fetched from the project's GitHub release on first use, checked against its SHA256, and cached under ~/.vtrace/pretrained so later runs and other configs reuse the same copy. No checkpoint is bundled in the repository or the wheel. 

--model maev2b             # VideoMAE V2 ViT-B, frozen + adapters (default)
--model maev2b-distilled   # same ViT-B, adapters distilled from V-JEPA 2
--model vjepa2             # V-JEPA 2 ViT-L, upper half fine-tuned
